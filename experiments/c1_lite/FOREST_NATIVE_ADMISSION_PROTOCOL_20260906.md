# Forest requested-schedule native continuation

The verified source campaign `forest_formal_20260906/attempt01` contains 131
events: 26 source-quotient link rejections, one exhaustive lower-first selector
rejection, and 104 events needing actual native checks. All 26 interface
rejections also have independent exact-root witnesses. These are not native
mesh failures and remain distinct from the next stage.

The 104 surviving events are evaluated independently against the same ordinary
five-element Forest baseline. The exact root is a mandatory requested output,
but is excluded from natural-frame denominators. It may be checked first to
short-circuit decisive failures. Survivors then require all ten selected natural
queries, including the eight window hits and two outside neighbors. No ideal
continuous-window failure or unrequested endpoint rounding condition is added.

## Explicit resource and preservation limits

- Use a private copy of the existing 1,096,080,433-byte cache. Temporary source
  copy budget is 2 GiB; no scene, RGB, video, full mesh sequence or environment
  installation. Remove the private copy after each attempt.
- Export one query at a time, all five elements, with <=2 GiB array bytes and
  <=8 GiB measured process RSS. No eleven-query full-mesh batch is retained.
- Native baseline arrays are immutable and reused across independent events
  at that query. Only compact plans, hashes, costs and witnesses persist, within
  a 100 MiB native-report budget. Hash actual proposed arrays before discarding
  them; publication of a schedule manifest waits for all required checks.
- The original cache and frozen production/source/library are unchanged. Bind
  all original inputs before/after; a private `log.txt` may append only, with
  at most 128 KiB per query and 4 MiB per attempt.
- The old 256 MiB source-cache and single-element WindowRuntime guards are not
  bypassed. A separate tested experiment adapter implements streamed input
  binding, five-element ledgers and one-query memory accounting explicitly.

## Native gates

Use the original camera transforms, dimensions, intrinsics and phase. Call
native `load_parameters` only, not tree construction or preprocessing. Verify
actual delta-T against the reconstructed input bit pattern.

For each requested active query, require actual raw identity status READY,
complete owner/face alignment, unique boundary SourceVID to actual-index mapping,
exact suppression of the two source faces and every replica owner, and the
actual binary32 graph-fan and interface tests. Other elements retain distinct
identity namespaces and are included in retained-geometry contact checking.

Strict represented-coordinate AABB separation is sufficient. Ambiguous contact
requires exact shared-feature/separating-plane checks. Missing a sufficient
separator is UNKNOWN, never a demonstrated intersection. Decisive local graph
or interface failures carry actual-coordinate/index witnesses and may reject
the fixed policy without executing later queries.

For a successful query, construct the proposed arrays transiently and verify
that all old vertices/tags, all retained face rows and every other element are
byte-identical. No baseline is mutated. Each event's requested schedule commits
only if every query passes, source inputs remain bound and no partial output
has escaped. Failed events retain the entire ordinary schedule; record discarded
proposals but do not present their hashes as committed treatment results.

## Observer-capacity handling

The frozen native observer has explicit 250,000-row guards. A capacity failure
is an instrumentation UNKNOWN, not method rejection. First measure the real
baseline and preserve this attempt's result. If necessary, create a separately
named, provenance-bound observer-only build with declared bounded capacity.
Keep the frozen build unchanged and verify that enabled/disabled observation
and the original library produce byte-identical ordinary meshes. No change to
slice geometry, owner identity definitions or acceptance gates is authorized
by a capacity-only instrumentation adjustment.
