# A/B 预实验结果 — 2026-09-06

本轮 A/B 已完成，未接入生产运行流程、未渲染长视频、未提交或推送 Git。
保留全部四个既定 demo 事件，没有换事件、改窗口或放宽失败条件来筛选正结果。

**结论：已得到局部几何改善及整窗局部正确性的证据，但还不能证明完整方法
全局安全，也不能宣称比原论文的视觉结果更好。** 外部兼容性尚未认证，
因此停止在离线审计阶段，没有输出未经认证的连续时间窗运行时补丁。

固定原窗口，每事件 33 个时刻，空间 grid 32 / 64 / 128；各方法共享同一
XY 采样域及独立原 terrain 参考。比较 ordinary baseline、endpoint-chord
fan、root-centroid fan、BEB1-root fan，以及仅在 root 生效的 C0。

下表是 grid128 的**时间归一化平均绝对高度误差积分估计**，下降为更好：

E2 = 0.9273 / 0.9263 / 0.9261%；E3 全为 0。这是分辨率敏感性检查，
不是新增独立案例或统计显著性证明。

必须一并保留的负结果和范围：

- E2 相对 centroid 的逐时刻最大高度误差，在 grid128 有 **+8.9461e-6**
  的最大回退；不能声称所有时刻、所有指标都更好。窗口内最坏采样误差也没有
  降低，端点保持不变。误差积分及最大值均来自有限采样，不是连续误差上界。
- E3 的两个 root 中心并不相同，但源面与中心都在 `z=0`，只是同一平面的
  不同细分，因此零收益有明确几何原因。
- E1 的 binary64 midpoint 距保存的源对角线约 `6.54e-17`，虽极小，仍不满足
  既定精确共线契约。prospective binary32 两端约 `3.51e-8 / 2.06e-8`，也未
  通过。没有放宽容差或替换事件。这是数值表示契约不支持，不是可见破洞或
  数学构造无解；A 理想坐标模型通过不能替代这一检查。
- 三种 fan 均新增一个中心、四张扇面，增量 occupancy 查询为零；历史 BEB1
  anchor 构造成本没有计时，**不能声称端到端等成本**。参考评测共用 297 个
  批次、1,108,784 个查询点，它们不是新增方法构造查询。
- C0 只在单个 root 改动，在连续时间积分中为零测度；没有利用离散积分的
  root 权重给它虚构非零持续收益。

`COMPLETE_WITH_UNSUPPORTED_OR_ERRORS` 中的 `ERROR` 是通用命名，并不表示

## 实际 C++ 基线核验

完成 4 事件 × 5 时刻 × raw / extra_smooth × OMP 1 / 8 = **80 次小切片**。
这不是 C1 运行时实验：没有加载新窗口计划，也没有渲染。

- 所有对应时刻 / 平滑选项的 OMP 1/8 mesh hash 一致。
- 四事件 root 的 raw vertices / faces / tags 均逐数组等于冻结 C0 baseline。
- raw 与 extra_smooth 的全网格不同，不能混用为同一个基线。
- 选定两张 source face 的有向坐标三元组在所有检查中各匹配一次。
- E3 前四个检查时刻，一个边界坐标对应两个不同运行时顶点；上端点则唯一。
  因而**坐标查找不能替代 SourceVID 身份**。没有把基线已有的同坐标顶点
  当作这轮算法新增缺陷。E0 / E1 / E2 的所查边界坐标均唯一。

八份小型 JSON 已保存在 [runtime_baseline](runtime_baseline/)；包含实际
加载的 `core.so` 与脚本哈希。原始缓存未被修改。

## 为什么本轮没有继续长视频或 Forest 普查

完整窗口尚未获准接入运行流程，不能把离线局部曲线包装为默认渲染流程的
warped SSIM 改善。本轮数据不是 Hausdorff、SSIM、拓扑修复或六场景覆盖率。
三个可测事件的 ordinary source face / owner 签名在 33 个时刻均不变，
没有在这些案例中展示对角配对切换或可见 popping 的修复。

按既有 demo 时间映射及原 24fps 半帧相位，E0 窗口命中一帧；E1 不命中；
E2 / E3 命中同一帧。这也不支持将当前收益外推为全视频均值的明显提升。

现有两套真实 Forest 缓存（`forest96-four-baseline-pilot-20260905` 与
`render-benchmark-960x540-8192-20260905`）的 OpaqueTerrain / atmosphere
四份 manifest 均记录 `event_registry_enabled=false`、
`provenance_enabled=false`、`provenance_requested=false`，且没有现成
registry / owner sidecars 可直接普查。要做真实场景覆盖率，需要在新路径
生成带 event / provenance 的匹配缓存，不能只对旧缓存打开开关。

现有两份非空 demo registry 实为同一副本：34 observations、3 个精确根、
4 个 canonical events，不能累加为 68 / 6 / 8。四例属于同一 demo 族，
E2 与 E3 同根，不能作为四个独立真实场景。
