# Completion of finite-query contact checks

The corrected original-SourceVID native03 campaign exposes finite-query
UNKNOWN results where the original sufficient separating tests do not decide
a retained triangle. UNKNOWN is not intersection and is not a policy rejection.

A subsequent explicitly enabled `--exact-contact-fallback` campaign uses the
same source contracts, rounded native geometry, strict-XY and regular-interface
gates, five-element namespaces, and allowed shared-feature contact policy.
For each undecided retained triangle, each of the four actual fan triangles is
tested by exact rational barycentric feasibility. Four PASS results certify
that retained triangle; one intersection point outside the allowed shared
feature is a decisive fixed-policy rejection. Arithmetic/input failures remain
UNKNOWN. No failed sufficient separator is itself counted as an intersection.

Each triangle pair has a 4096-bit rational bound and 100000 arithmetic-operation
bound, with at most 20 basis candidates. The new fan-center identity is the actual
appended vertex index in its own element. The original baseline is immutable.
Only the test capability is completed; no precondition is relaxed to improve
the measured rate. Prior native03 results and their source hashes are retained.

A forbidden-contact witness does not establish that the intersection is new
relative to the baseline. Such a novelty claim would need a separate comparison
that is not part of this admission campaign.
